# Brown Bag Liquor — Easy Edit Website

This is a standalone browser version of the Brown Bag Liquor website.

Open **`index.html`** directly, or double-click **`OPEN WEBSITE IN EDGE.bat`**.

It does **not** require Python, Docker, Node, a local server, or a database.

## Pages

- `index.html` — Home
- `stores.html` — Our Stores
- `categories.html` — Categories
- `specials.html` — Specials
- `about.html` — About
- `contact.html` — Contact

## Where to edit

- **Text and page content:** edit the corresponding `.html` file.
- **Design:** `assets/styles.css`
- **Interactions:** `assets/app.js`
- **Photography:** `assets/images/`

See **`EDIT GUIDE.txt`** for step-by-step instructions.
